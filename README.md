# TapRush

TapRush is a simple and fast browser-based tap counter game. Tap as fast as you can, build your combo, and try to beat your highest score.

Features

- Tap counter
- Real-time CPS (Clicks/Taps Per Second)
- Combo system
- Free Tap mode
- 10-second challenge
- 30-second challenge
- 100-tap progress challenge
- Local high score
- Optional tap sound
- Tap animations
- Responsive mobile-friendly interface
- No backend required
- Single HTML file

Getting Started

No installation or dependencies are required.

Just open:

index.html

in your browser.

Deploy

TapRush can be deployed easily using static hosting services such as Vercel or GitHub Pages.

Vercel

1. Import this repository into Vercel.
2. Select the project.
3. Deploy.

GitHub Pages

1. Open the repository settings.
2. Go to Pages.
3. Select the branch containing "index.html".
4. Set the folder to "/root".
5. Save.

Tech Stack

- HTML
- CSS
- Vanilla JavaScript

No frameworks. No external dependencies.

Data & Privacy

TapRush runs entirely in the browser.

Your high score is stored locally using "localStorage" and is not uploaded to a server.
